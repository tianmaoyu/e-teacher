- 构建命令：`cd android && JAVA_HOME=... ANDROID_HOME=... /Users/eric/.toolchains/gradle-9.7.1/bin/gradle assembleDebug`
- **AGP 9 坑（2026 生态已全量迁移）**：
  - AGP 9.0+ 内置 Kotlin，**必须移除 `org.jetbrains.kotlin.android` 插件**，否则报
    "Cannot add extension with name 'kotlin'"
  - AGP 9.4.0 内置 KGP 2.2.10；用新 Kotlin 需在顶层 build.gradle.kts 加
    `buildscript { dependencies { classpath("org.jetbrains.kotlin:kotlin-gradle-plugin:X.Y.Z") } }`
  - 最低 Gradle 9.1 / JDK 17；`isMinifyEnabled` 等 legacy DSL 仍可用
  - Compose BOM 2026.09 / core-ktx 1.19 / okhttp 5.5 要求 compileSdk 37
  - `android.nonTransitiveRClass` 开关已移除（默认即非传递）
- 推送凭证：GitHub MCP 集成只读（建仓/推送均 403）；钥匙串里的 PAT 已失效；
  **SSH key `~/.ssh/id_rsa`（口令用户掌握）可用**：起独立 agent
  `ssh-agent -a /tmp/speakmate-ssh.sock` + expect 输口令 ssh-add，然后
  `SSH_AUTH_SOCK=/tmp/speakmate-ssh.sock git push git@github.com:...`
- 本机出口 IP 对 api.github.com 匿名限流频繁耗尽，用
  `https://github.com/<owner>/<repo>/actions/workflows/<f>.yml/badge.svg` 查 CI 状态
